## 一、组件装在哪

打印组件装在**操作员本机**，不是服务器。换电脑要重新装。

## 二、排查顺序

1. 组件是否在运行（看托盘图标）；
2. 端口 127.0.0.1:13528 是否被占用；
3. 浏览器是否拦截了本地回环请求；
4. 组件版本是否低于样例版本 9.3.0.0。

## 三、常见报错

**Q：打印时 ERP 无法与组件连接，如何排查？**

A：先确认组件在跑，再检查 127.0.0.1 是否被安全软件拦截。

**Q：组件报 Java heap space**

A：一次打印的单量太大。分批打印，**单批不超过 200 单**。

**Q：设置了开机自启动但没有自动启动**

A：把组件的快捷方式放进「启动」文件夹，并确认它不是以管理员身份运行的——
管理员身份的程序不会被普通用户会话拉起。
