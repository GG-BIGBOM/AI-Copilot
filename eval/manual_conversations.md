# 多轮人工验收集（M13 P4）

> **这不是自动化评测，是发版前的 checklist。** 20 组、每组 3–8 轮，
> 一个人照着念一遍，把每组的「重点看什么」逐条对一遍。

## 为什么要有这一份

离线单题评测覆盖不到 Agent 最容易坏的地方。`dataset.yaml` 里每道题都是
**一句独立的、写得很规整的问题**，而真人不是这么说话的：

```
追问        「那不良品呢」
省略主语    「在哪里设置」
改口        「不是，我说供应商退货」
说错名词    「面单模版」「电子面单模板」「快递单模板」
继续上一话题「那退款的呢」
突然改条件  「刚才说错了，是 8 个店」
```

这一类失败在离线题集上**结构性地测不出来**——不是题出得不好，是那份题集里
根本没有「上一轮」。M10 那道硬防线（`agent/guard.py`）就是这么来的：

```
用户：退货入库怎么操作   → 调 answer_kb，答对，5 条引用
用户：那不良品呢         → 一个工具都没调，直接给出「方式1：勾选残次品入库…[4]」
```

那段话读起来和查来的一模一样、还带着 `[4]`，但页面上 **0 条引用可点**——
`[4]` 指向的是**上一轮**的来源。离线路由评测没抓到，因为那份题集里的 history
是短的合成字符串，喂不出这个行为。

**所以这一份的价值全在「第二轮以后」。** 第一轮答得好不好，别的评测已经在管了。

## 怎么用

- **发版前跑一遍**，尤其是动过 prompt、路由、工具、history 截断的时候
- 在**真实前端**上点，不要用 curl：要看的东西里有一半是页面上的
  （引用能不能点、`[图1]` 有没有换成真图、停止生成之后刷新还在不在）
- 一组从头到尾用**同一个会话**，中途别新开
- 发现问题就把那一轮的 `trace_id` 记下来（👎 一下最省事），
  它能把当时的检索链路整条捞出来

## 通用判据（每一组都要看）

| # | 看什么 | 坏掉的样子 |
|---|---|---|
| 1 | 有没有丢上下文 | 「那不良品呢」被当成一个全新问题重新检索 |
| 2 | 有没有重复问已经问过的 | 用户说了「淘宝拼多多」，下一轮又问「您有哪些平台」 |
| 3 | 主体有没有搞错 | 上一轮在说采购退货，这一轮答成了销售退货 |
| 4 | 有没有错误触发寒暄短路 | 「好的谢谢，那预售呢」被 canned 成「不客气」 |
| 5 | 该检索的有没有检索 | **一个工具都没调却给出带界面路径的答案**（M10 那道防线要拦的） |
| 6 | 有没有乱调一堆工具 | 一个纯问答轮调了 `save_requirement` |
| 7 | `answer_kb` 有没有重复调 | 同一轮里检索两次、引用编号错位 |
| 8 | 引用能不能点、图是不是真图 | 页面上挂着 5 条来源但正文说「暂无此内容」；裸的 `[图1]` |

## 一、追问与省略主语

### 组 1 — 退货入库 → 那不良品呢（M10 硬防线的原始样本）

```
1  退货入库怎么操作？
2  那不良品呢？
3  残次品仓要提前建好吗？
```

**重点**：第 2 轮是这整份文档的起因。它必须**去检索**，不能拿上一轮的
材料直接写。看 trace 的 `tools`：空数组 + 一段带界面路径的答案 = 破线。

### 组 2 — 改口纠正主体

```
1  退货怎么操作？
2  那不良品呢？
3  不是，我说的是供应商退货
4  那个要先审核吗？
```

**重点**：第 3 轮的「不是，我说的是」必须能把主体从销售退货切到采购退货。
第 4 轮的「那个」指的是采购退货单，不是第 2 轮的不良品。

### 组 3 — 纯代词追问

```
1  电子面单模板在哪里配置？
2  小红书的呢？
3  它和唯品会的有什么不一样？
```

**重点**：第 2、3 轮都没有主语。第 3 轮是**跨平台对比**——
两边的材料都要在，不能拿一边的说法套到另一边。

### 组 4 — 追问一个材料里没有的分支

```
1  采购入库有哪几种方式？
2  那 Lazada 的呢？
```

**重点**：第 2 轮必须拒答。⚠️ 上一轮刚给过一段结构完整的入库流程，
模型这时最容易把它照抄一遍、把平台名换掉——这是压缩版 prompt 实测破线的形态。

## 二、多轮收集需求（Agent 那条路）

### 组 5 — 正常出方案

```
1  帮我做个实施方案
2  淘宝、拼多多
3  5 个店
4  自营，一个仓
5  平峰日均 500 单，大促 2000 单
6  中通、顺丰
7  没有特殊业务
8  （等它给出清单）导出来
```

**重点**：每一轮**只问没答过的**。第 5 轮要真的出 xlsx 且能下载。
看 trace：这几轮应该分别落在 `save_requirement` / `generate_plan` / `export_excel` 上。

### 组 6 — 中途改口

```
1  帮我做实施方案
2  淘宝拼多多
3  5 个店
4  刚才说错了，是 8 个
5  继续
```

**重点**：第 4 轮要把 5 改成 8，**不能**变成「新加 8 个店」或者重新问一遍平台。
第 5 轮的「继续」不能被当成闲聊。

### 组 7 — 收集到一半插一个知识问题

```
1  帮我做实施方案
2  淘宝
3  等一下，虚拟仓是什么？
4  好，继续。3 个店
```

**重点**：第 3 轮要**去查知识库**（或用常识答概念），
第 4 轮要能回到收集流程，而且**记得第 2 轮已经答过平台了**。
⚠️ 这是最容易断的一组：`profile` 落库没落住的话，第 4 轮会重问平台。

### 组 8 — 一句话给全

```
1  我有淘宝拼多多抖音三个平台，一共 12 个店，两个自营仓，平峰日均 1000 单、
   大促 5000 单，用中通和圆通，没有特殊业务，帮我出方案
2  导出
```

**重点**：七个需求字段已经一轮给全，**不能再逐个追问**。

## 三、概念与常识（M12 那条线）

### 组 9 — 概念 → 概念 → 对比

```
1  什么是分销限价？
2  品牌方呢？
3  那他们和经销商什么区别？
```

**重点**：这三轮就是 M12 的起因。第 2 轮曾被硬防线整段换成
「知识库暂无此内容」。三轮都要给出实质回答，**且不许挂 [n]**
（除非真有材料支持）。

### 组 10 — 常识问题滑向操作问题

```
1  电子面单是什么？
2  那在系统里怎么配？
3  京东的呢？
```

**重点**：第 1 轮可以用常识答；第 2、3 轮**必须有出处**。
这一组量的正是那条线本身——同一个话题，两轮之间跨过了红线。

### 组 11 — 概念问完追一个数

```
1  什么叫安全库存？
2  系统里默认是多少？
```

**重点**：第 1 轮答概念，第 2 轮**必须拒答**（库里没有这个默认值）。
⚠️ 第 1 轮刚讲完一段自信的概念，第 2 轮最容易顺着编一个数出来。

## 四、寒暄与边界

### 组 12 — 寒暄夹在中间

```
1  你好
2  采购退货怎么弄
3  好的谢谢
4  那采购结算呢
```

**重点**：第 1、3 轮走 canned（0 成本）。**第 4 轮不能被短路**——
它以「那」开头、跟在一句道谢后面，是寒暄误判最容易发生的位置。

### 组 13 — 问能力

```
1  你能干什么？
2  那你能看我上传的文档吗？
3  我传过哪些？
```

**重点**：第 1 轮 canned。第 3 轮要调 `my_documents`，**不能编一个文档列表出来**。

### 组 14 — 空输入与超短输入

```
1  ？
2  在
3  订单审核在哪
```

**重点**：前两轮不能崩、不能触发一次昂贵的检索。第 3 轮正常答。

## 五、私有库与主体（M11 P3）

### 组 15 — 我们家的约定

```
1  我们的组合装要拆吗？
2  那对账呢？
3  公共的做法是什么？
```

**前提**：这个账号要**传过**自己的文档。
**重点**：前两轮以「你的文档」为准；第 3 轮问的是通用做法，
**只能引公共知识库**，不能把某一家的约定说成通用做法。

### 组 16 — 点名另一个客户

```
1  星辰电商的对账以什么为准？
2  远岸家居呢？
3  他们俩有什么不一样？
```

**前提**：账号里有这两家的文档。
**重点**：⚠️ 第 2 轮的「远岸家居」——`_SUBJECT_SUFFIX_RE` 那张后缀表**天生不全**，
2026-08-20 实测就漏过这一条。漏判的表现是：意思对，但不是那句兜底话术，
于是页面上会是「没有」底下挂着五条来源。

### 组 17 — 私有库里没有的事

```
1  我们的发票怎么开？
2  那我们的快递用哪家？
```

**重点**：材料里没有讲这家的这件事时，要回**那句兜底话术**，
不要罗列材料里都写了些什么。

## 六、稳定性与前端

### 组 18 — 停止生成后接着聊

```
1  盘点的完整流程是怎样的？   ← 出字的过程中点「停止生成」
2  （刷新页面）继续说
```

**重点**：刷新后**已经流出来的半截答案还在**（边流边落库）。
第 2 轮的「继续说」要接得上，不是重新开始。
顺便看 trace：被中断的那一轮**也要有一行**（`shield` 住取消）。

### 组 19 — 长会话的上下文截断

```
1–6  连问六个不相关的问题
7    第一个问题我问的是什么？
8    那个功能在哪配置来着？
```

**重点**：`HISTORY_TURNS` 只带最近 6 轮。第 7 轮**答不出来是正常的**，
但**不能编**一个出来。第 8 轮的「那个」指第 7 轮提到的东西。

### 组 20 — 换档位

```
1  采购退货怎么操作？        ← 简答档
2  （切到详解档）再说详细点
3  刚才那个结算呢
```

**重点**：切档之后上下文不能丢。⚠️ 详解档正文首字要 8~60 秒，
中间应该能看见推理草稿在动——**不能是一片空白**。
第 3 轮回到简答档时，「刚才那个」仍然指采购退货。
